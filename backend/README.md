# Backend — Spring Boot 4.0.0

Esta pasta contém o serviço backend usando Spring Boot 4.0.0 (alvo Java 21).

Estrutura:
- `src/main/java` — código-fonte Java
- `src/main/resources` — recursos (application.yml, etc.)
- `pom.xml` — build Maven

Como executar localmente:

```bash
# precisa de JDK 21 e Maven
mvn -f backend/pom.xml spring-boot:run
```
