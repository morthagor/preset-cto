🚀 INICIALIZAR RÁPIDO
=====================

OPÇÃO 1: Teste Mobile App (Recomendado para iniciar)
───────────────────────────────────────────────────

$ cd cto/mobile
$ npm start

Opções no menu:
  a → Android emulator
  w → Web browser (teste rápido)
  i → iOS simulator (Mac apenas)
  r → Reload
  q → Quit


OPÇÃO 2: Rodar Backend (Java)
──────────────────────────────

$ cd cto/backend
$ mvn spring-boot:run

Ou com Docker (PostgreSQL, Redis, RabbitMQ):
$ docker-compose up -d
$ mvn spring-boot:run


OPÇÃO 3: Rodar Tudo Junto (Recomendado)
────────────────────────────────────────

Terminal 1 - Services (Docker)
$ docker-compose up -d

Terminal 2 - Backend API
$ cd backend && mvn spring-boot:run

Terminal 3 - Mobile App
$ cd mobile && npm start
[Pressione 'a' para Android ou 'w' para Web]

🔧 ARQUITETURA DE SYNC
======================

Offline-First:
  Quando offline → salva localmente
  Quando online → sincroniza com backend

Backend endpoints:
  POST /api/auth/login              (autenticação)
  POST /api/sync/push               (enviar mudanças)
  GET  /api/sync/pull               (buscar atualizações)
  GET  /api/updates/mobile          (check versão app)

❓ PROBLEMAS COMUNS
===================

npm install falha:
  $ npm install --legacy-peer-deps

Expo não inicia:
  $ npm start -- --clear

Emulador Android não abre:
  $ emulator -list-avds
  $ emulator -avd <seu_avd> &
  $ npm run android

Backend porta 8080 em uso:
  $ lsof -i :8080
  $ kill -9 <PID>
